# Charity Organization Website - Project Management

A Software Project Management project focused on planning, managing, and controlling the development of a Charity Organization Website sponsored by UNICEF.

## Project Scope
- Project Charter
- Project Management Plan (PMP)
- Scope Management
- Schedule Management
- Cost Management
- Quality Management
- Risk Management
- Resource Management
- Communication Management

## Key Deliverables
- Work Breakdown Structure (WBS)
- Activity List
- Network Diagram
- Critical Path Analysis
- Gantt Chart
- Risk Register
- Requirements Traceability Matrix (RTM)
- Responsibility Assignment Matrix (RAM)
- RACI Chart

## Project Objectives
- Develop a charity website with 8 functional pages
- Improve donation accessibility
- Increase volunteer engagement
- Provide a structured digital presence for the organization

## Tools & Methodologies
- PMBOK Framework
- WBS
- CPM
- PERT
- Earned Value Management (EVM)
- Risk Analysis
- Jira
- Microsoft Project
